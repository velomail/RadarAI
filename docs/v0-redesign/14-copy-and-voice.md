# Copy and voice

## Brand rules

- Always **RadarAI** — never "Radar" alone in user-facing copy
- Honest about gaps and limits — no fake urgency or guaranteed offers
- Utility framing: user controls **when** to search
- Say **Adzuna** when naming job data source — do not claim LinkedIn or "all boards"

## Tone

Professional, calm, trustworthy B2C. Short sentences. No hype slang. Explain AI value in plain English.

### Limits

```

```

### Trust (DataTrustNotice)

- **Your data stays yours**
- Resume PDFs stored in private Supabase Storage
- Resume text used only to score jobs — never sold
- Delete account data anytime from Settings

## Words to avoid

- Unlimited (free tier)
- LinkedIn scraping / all job boards
- Subscribe now / Buy Pro
- Magic link / password
- Guaranteed interview / dream job
